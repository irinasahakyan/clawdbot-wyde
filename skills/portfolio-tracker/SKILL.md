# Portfolio Tracker Skill

## Purpose
Track wallet balances and performance across chains.

## Supported Chains
- Ethereum
- Base
- Arbitrum
- Polygon

## Commands Users Can Say

- "Show my portfolio"
- "What's my balance?"
- "How much ETH do I have?"
- "Show my P&L"
- "What did I make today?"

## Example Response

When user asks "show my portfolio":
```
📊 Your Portfolio

Total Value: $12,450.25 (+2.3% today)

Holdings:
├─ ETH: 1.5 ($4,875.00)
├─ USDC: 5,000.00
├─ WYDE: 25,000 ($1,250.00)
└─ Other: $1,325.25

Today's P&L: +$280.50 📈
Impact Generated: $8.45 🌍

Tip: Your WYDE tokens are earning 12% APY in the pool!
```
