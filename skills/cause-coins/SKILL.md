# Cause Coins Tracking Skill

## Purpose
Track WYDE cause coins - tokens where trading fees fund real charities.

## Cause Categories
- 🌍 Environmental (climate, conservation)
- 📚 Education (scholarships, literacy)
- ❤️ Health (medical research)
- 🏘️ Community (local initiatives)
- 🐾 Animal Welfare (shelters, wildlife)

## Commands Users Can Say

- "Show impact report"
- "How much has WYDE donated?"
- "What causes are we funding?"
- "Show environmental impact"
- "Top causes this month"

## Example Response

When user asks "show impact report":
```
🌍 WYDE Impact Report - This Month

Total Impact Generated: $15,230

By Cause:
├─ 🌍 Environmental: $4,520 (29.7%)
│   └─ 1,808 trees planted
├─ 📚 Education: $3,810 (25.0%)
│   └─ 4 scholarships funded
├─ ❤️ Health: $3,200 (21.0%)
├─ 🏘️ Community: $2,100 (13.8%)
└─ 🐾 Animal Welfare: $1,600 (10.5%)

Your contribution: $45.30 🎉
```
