# Available Tools for Clawdbot

## Trading Tools
- `swap`: Execute token swaps via DEX aggregators
- `quote`: Get price quotes without execution
- `limit_order`: Set conditional orders

## Data Tools
- `price_feed`: Real-time price data
- `pool_data`: Liquidity pool information
- `tvl_query`: Protocol TVL data
- `wallet_balance`: Check wallet balances

## Impact Tools
- `impact_calculator`: Calculate charitable allocation
- `cause_stats`: Get cause coin statistics
- `impact_report`: Generate impact reports

## Monitoring Tools
- `whale_tracker`: Monitor large transactions
- `alert_manager`: Configure and manage alerts
- `gas_tracker`: Monitor gas prices

## Integration Tools
- `discord_notify`: Send Discord notifications
- `chart_generator`: Create price/impact charts
- `export_data`: Export data to CSV/JSON
